## 📋 项目概述

### 项目名称
Kiro OAuth 2 API - AWS CodeWhisperer (Kiro) 到 Claude API 的代理服务

### 项目描述
这是一个代理服务,将 AWS CodeWhisperer (Kiro) 的 OAuth 2.0 认证转换为 Claude API 兼容格式,支持 Claude Code、Cursor 等 AI 编程工具,并提供完整的 Provider Pool 管理功能。

### 技术栈
- **后端**: Node.js (ES Modules), better-sqlite3, Redis, undici
- **前端**: Next.js 16.1.1, React
- **认证**: AWS OAuth 2.0, Google Auth Library
- **数据库**: SQLite (账号池), Redis (缓存)
- **进程管理**: PM2
